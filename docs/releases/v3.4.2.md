# Freshservice Knowledge Base Exporter v3.4.2

**First end-to-end validated stable release** of the English-language Windows PowerShell exporter.

### Highlights

- Automatic inventory download through a scheduled Freshservice **Solutions Analytics Data Export**.
- Manual CSV/XLSX inventory import when a scheduled export is unavailable.
- Article ID deduplication, API v2 article retrieval, and category/folder organization.
- Individual HTML and JSON article files, consolidated CSV/JSON inventories, and execution logs.
- Windows Forms graphical interface with encrypted local preferences.
- Windows-safe filenames and directory names, including trailing whitespace and periods.
- Accurate separation of successful API reads from successful HTML/JSON file saves.

### Verified end-to-end result — October 19, 2026

- **920/920** unique article API reads succeeded.
- **920/920** HTML + JSON article pairs were saved.
- **0** failed API reads.
- **0** failed file writes.
- **0** logged errors.
- **21** categories and **96** folders were retrieved.

The tested input contained 1,337 reporting rows. The optional XLSX inventory was not generated because Microsoft Excel was unavailable, but the CSV inventory was successfully created.

### Installation

Download the script **[Freshservice-KnowledgeBase-Exporter.ps1](https://github.com/Joystrife/freshservice-knowledge-base-exporter/blob/main/Freshservice-KnowledgeBase-Exporter.ps1)** using GitHub's **Raw → Download raw file** option. Keep its **UTF-8 with BOM** encoding for Windows PowerShell 5.1.

Run from Windows PowerShell:

```powershell
.\Freshservice-KnowledgeBase-Exporter.ps1
```

Follow the [user guide](https://github.com/Joystrife/freshservice-knowledge-base-exporter/blob/main/docs/USER_GUIDE.md) to configure your Freshservice domain, API credentials, and either an Analytics Data Export API URL or a CSV/XLSX reporting file.

### Notes

- The automated mode reads the **latest already-generated scheduled Analytics export**; it does not trigger a new Freshservice Analytics export.
- Only export data you are authorized to access. Do not publish your API key, Analytics export URL, or exported Knowledge Base articles.
- This is an independent community tool, not an official Freshworks product.
- Successful testing on one Windows/Freshservice environment does not guarantee compatibility with every tenant or configuration.
